# GitHub 한국어+

GitHub UI를 빠르고 자연스럽게 한국어로 바꾸는 Manifest V3 Chrome/Chromium 확장 프로그램입니다.

## 핵심 목표

- **완전 로컬 UI 번역**: 기본 기능은 외부 번역 서버, API, 원격 코드, 광고/스폰서 요청을 사용하지 않습니다.
- **최소 권한**: Chrome API 권한은 `storage` 하나만 사용합니다.
- **대형 한국어 사전**: 기존 GitHub 한국어 프로젝트의 페이지별 사전과 정규식 규칙을 계승하고 최신 MIT 한국어 사전을 보강합니다.
- **동적 GitHub 대응**: Turbo 화면 전환과 MutationObserver를 지원하며, 변경된 영역만 idle 배치 처리합니다.
- **코드/README 보호**: 기존 사전의 페이지별 ignore 규칙을 사용해 코드, Markdown 본문, 사용자 작성 콘텐츠의 오번역을 줄입니다.
- **개발자 친화 용어**: `저장소 → 리포지토리`, `끌어오기 요청 → 풀 리퀘스트`, `분기 → 브랜치` 등의 개발자 용어 모드를 기본으로 제공합니다.
- **한국어 조사 보정**: 번역 결과의 `은/는`, `이/가`, `을/를`, `와/과` 등을 문맥에 맞춰 보정합니다.

중복 항목이 있으므로 위 숫자를 단순 합산한 값이 실제 고유 번역 문자열 수와 정확히 일치하지는 않습니다.

## 설치 (개발 버전)

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. `D:\GitHubKorean` 폴더를 선택합니다.
5. GitHub 페이지를 새로고침합니다.

## 설정

확장 아이콘을 눌러 다음을 변경할 수 있습니다.

- 한국어 번역
- 영문 개발 용어에 가까운 표현 사용 (기본 OFF)
- 한국어 조사 자동 보정
- 성능 로그

번역 엔진에 영향을 주는 설정을 변경하면 현재 GitHub 페이지가 자동 새로고침됩니다.

## 개인정보 및 네트워크

v0.1.0 기본 기능은 네트워크 요청을 하지 않습니다. 설정은 `chrome.storage.local`에만 저장합니다.

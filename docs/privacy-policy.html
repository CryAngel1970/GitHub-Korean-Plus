GitHub 한국어+ 개인정보처리방침

최종 업데이트: 2026-09-25

GitHub 한국어+는 GitHub 인터페이스를 한국어로 번역하는 Chrome/Chromium 확장 프로그램입니다.

수집하는 개인정보

이 확장 프로그램은 이름, 이메일 주소, GitHub 계정 정보, 비밀번호, 인증 토큰, 방문 기록, 결제 정보 등 사용자를 식별할 수 있는 개인정보를 수집하지 않습니다.

데이터 전송

번역 기능은 확장 프로그램에 포함된 로컬 번역 사전으로 동작합니다. 사용자 데이터나 GitHub 페이지의 내용을 외부 번역 서버, 분석 서비스 또는 광고 서버로 전송하지 않습니다.

로컬 저장

사용자가 선택한 번역 사용 여부, 용어 표시 방식, 한국어 조사 보정, 성능 로그 설정만 Chrome의 storage.local에 저장합니다. 이 설정은 사용자 브라우저 안에서만 사용됩니다.

GitHub 페이지 접근

확장 프로그램은 GitHub 인터페이스를 한국어로 바꾸기 위해 manifest에 선언된 GitHub 관련 페이지에서만 실행됩니다. 코드, README, 이슈/토론/끌어오기 요청의 사용자 작성 내용을 수집하거나 외부로 전송하지 않습니다.

제3자 제공 및 판매

사용자 데이터를 제3자에게 판매하거나 제공하지 않습니다. 광고 SDK나 사용자 추적 SDK를 포함하지 않습니다.

문의

프로젝트 관련 문의와 문제 보고는 GitHub 저장소의 Issues를 이용할 수 있습니다.

이 정책은 확장 프로그램의 기능이 변경되어 데이터 처리 방식이 달라질 경우 함께 업데이트됩니다.
